# Specs

Feature and requirement specs for SLDB Payroll: what to build and how, written before or alongside the work.

- `specs/` — specs for features (often spanning `frontend/`, `backend/` and `database/`).
- `docs/` — reference and explanatory material about existing systems and data.

## Naming

`NNN-short-kebab-title.md`, numbered in order of creation, e.g. `001-payroll-run.md`.
